# Requisitos Iniciais — PharmaLink

## Objetivo

Este documento registra o entendimento inicial da equipe sobre as principais necessidades e funcionalidades presentes no PharmaLink.

Os requisitos apresentados nesta etapa são iniciais e poderão ser revisados e detalhados durante a evolução do projeto.

## Requisitos Funcionais

### RF01 — Gerenciar medicamentos

O sistema deve permitir o gerenciamento das informações dos medicamentos.

### RF02 — Controlar estoque

O sistema deve permitir o controle do estoque de medicamentos, considerando seus lotes e quantidades.

### RF03 — Criar pedidos

O sistema deve permitir a criação de pedidos de medicamentos.

### RF04 — Adicionar medicamentos ao pedido

O sistema deve permitir adicionar medicamentos disponíveis aos pedidos.

### RF05 — Tratar medicamentos que exigem receita

O sistema deve considerar a necessidade de receita para medicamentos que possuem essa exigência.

### RF06 — Processar pagamento

O sistema deve permitir o processamento do pagamento dos pedidos.

### RF07 — Solicitar entrega

O sistema deve permitir o envio das informações necessárias para realização da entrega do pedido.

### RF08 — Enviar notificações

O sistema deve permitir o envio de notificações relacionadas ao pedido.

## Requisitos Não Funcionais

### RNF01 — Segurança

O sistema deve considerar a segurança das informações e das operações realizadas.

### RNF02 — Confiabilidade

O sistema deve manter informações consistentes relacionadas aos pedidos, estoque e pagamentos.

### RNF03 — Manutenibilidade

O sistema deve possuir uma organização que permita manutenção e evolução ao longo do projeto.

### RNF04 — Integração

O sistema deve permitir comunicação com os serviços externos necessários para pagamento, entrega e notificações.

## Observações

Os requisitos apresentados neste documento representam apenas um levantamento inicial realizado a partir da análise do projeto legado.

Nesta etapa, não foram definidos critérios de aceitação detalhados para todos os requisitos.

O levantamento será revisado e complementado nas próximas aulas conforme a equipe aprofundar a análise do PharmaLink.
