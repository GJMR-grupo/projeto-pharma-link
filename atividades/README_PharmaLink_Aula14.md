# PharmaLink — Aula 14

## Tema
Strategy, Factory Method, Abstract Factory e Observer

## Situação do projeto
O PharmaLink contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. avaliar criticamente as implementações legadas dos quatro padrões;
2. aplicar Strategy a uma variação real, como descontos, política de entrega ou substituição de produto, quando pertinente;
3. avaliar criação de tipos de pedidos/objetos para justificar Factory Method;
4. modelar famílias coerentes de parceiros/serviços quando houver justificativa para Abstract Factory;
5. permitir múltiplos interessados em eventos pertinentes usando Observer;
6. revisar conjuntamente os seis padrões e produzir código, UML/Mermaid e ADR para cada padrão mantido.

## Dicas
- Não use padrão apenas para cumprir lista.
- Se uma implementação inicial só imita o padrão, explique por quê.

## Evidências mínimas da entrega
- Issue identificada como `Aula 14`.
- Branch sugerida: `aula-14`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- Quando houver código, incluir evidência de compilação/execução ou teste pertinente.
- PR ou registro equivalente permitindo revisão do grupo, quando aplicável.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
